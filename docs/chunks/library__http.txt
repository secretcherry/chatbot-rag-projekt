class http. HTTPStatus
Added in version 3.5. A subclass of enum.IntEnum that defines a set of HTTP status codes,
reason phrases and long descriptions written in English. Usage: >>> from http import HTTPStatus >>> HTTPStatus . OK HTTPStatus.OK >>> HTTPStatus . OK == 200 True >>> HTTPStatus .
