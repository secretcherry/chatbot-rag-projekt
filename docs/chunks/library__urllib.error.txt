# urllib.error — Exception classes raised by urllib.request

urllib.error
Source code: Lib/urllib/error.py
The urllib.error module defines the exception classes for exceptions
raised by urllib.request .  The base exception class is URLError .

exception urllib.error. HTTPError ( url , code , msg , hdrs , fp )
Though being an exception (a subclass of URLError ), an HTTPError can also function as a non-exceptional file-like return
value (the same thing that urlopen() returns).  This
is useful when handling exotic HTTP errors, such as requests for
authentication. url Contains the request URL.
